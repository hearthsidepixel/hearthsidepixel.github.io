Red Cardinal Color by Number

A red cardinal perched on a branch, with a dark face mask and an orange beak. Hidden in a numbered pixel grid: print it, match each code to its color and watch the red cardinal appear. Free for personal use.

How to color this page

  1. Download and print the PDF in black and white (page 2 is the answer).
  2. Find each code in the key and lay out the matching colors.
  3. Color one code at a time. Leave empty squares blank.
  4. Check the answer page if you are unsure.
