How to install

  1. Install the Modrinth App (or Prism Launcher).
  2. Download the .mrpack file from the attachments above.
  3. In the Modrinth App, click + → Import from file and pick the .mrpack. Prism: Add Instance → Import.
  4. Give Minecraft at least 4–6 GB of RAM in the instance settings.
  5. Press Play and start a new singleplayer world.

The launcher downloads every mod automatically on first launch, so the first start can take a few minutes.

Troubleshooting

  • Game crashes on start: make sure the instance uses Java 21 or newer and Minecraft 1.21.11.
  • The story mod is missing: import the whole .mrpack, don't copy single jars into an existing instance. Some launchers reset the mods folder when they sync a pack.
  • File removed after download: check your antivirus quarantine (Windows Security → Protection history).
